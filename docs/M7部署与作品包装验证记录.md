## 已实现交付

- 根目录 `compose.yaml`：固定种子 MySQL、持久化管理库、Spring Boot 后端和 Nginx/Nuxt 前端。
- `.env.example`：只包含本地占位值和端口，不包含模型 API Key 或真实数据库密码。
- `deploy/Dockerfile.database`：镜像构建期间运行数据生成器，不提交约 80 MB 的生成 SQL。
- `deploy/Dockerfile.backend`：Java 17 多阶段构建，运行阶段使用非 root 用户。
- `deploy/Dockerfile.frontend`：Node 22 + pnpm 11 静态构建，Nginx 代理 REST 与 SSE。
- `deploy/verify.sh`：Git Bash 下验证 Compose、前后端健康、A01-A06 数据断言和数据库只读权限；`verify.ps1` 仅作为兼容入口保留。
- 根 README：说明上游来源、个人改造、合成数据、实际评测、许可证、启动和安全边界。
- `作品架构与安全设计.md`：部署架构、ER 图、核心时序和纵深防御。
- `演示脚本.md` 与 `已知限制.md`：公开展示节奏和事实边界。
