## 交付目录

主要入口：`demo/enterprise-finance/`

- `config.json`：固定种子、数据规模、正常规则和异常注入参数。
- `generator/generate.py`：仅使用 Python 标准库的确定性生成器。
- `generator/test_generate.py`：记录数、唯一性、业务关系和重复生成测试。
- `sql/01_schema.sql`：数据库、表、主外键、检查约束和索引。
- `sql/02_seed_reference_data.sql`：8 个部门和 10 个 KPI 定义。
- `sql/03_validation_queries.sql`：数据完整性断言及 A01-A06 异常视图。
- `rebuild.ps1`、`rebuild.sh`：生成、测试、重建 MySQL 和执行 SQL 断言的一条命令入口。
- `docker-compose.yml`：独立 MySQL 8.4 验证环境，映射端口 `3307`。

生成的 `generated/04_generated_data.sql` 和 `manifest.json` 已通过目录内 `.gitignore` 排除，不提交约 8 MB 的派生数据文件。

## 安全与范围边界

- 生成器不访问网络或外部业务数据。
- 所有邮箱使用保留域名 `example.invalid`。
- 数据库密码只从运行时环境变量读取；未提供时重建脚本生成临时随机值，不写入仓库。
- 当前 root 用户只用于 M1 本地初始化和验证。只读账号、SQL 安全和权限范围属于后续安全里程碑。
- M1 未修改 Agent 工作流、语义模型、业务知识或前端页面。
