# 企业经营与财务数据分析 Agent 开发路线图

## 一、产品定位

这是一个个人开源的企业数据分析 Agent。它使用合成的 CRM、财务和 KPI 数据，让用户通过自然语言安全地查询经营指标、下钻异常、核对数据并生成分析报告。

项目价值不是复刻任何公司系统，而是展示以下能力：

- Java 与 Spring Boot 工程开发。
- StateGraph Agent 工作流。
- RAG 业务语义增强。
- NL2SQL 与多轮分析。
- 财务数据安全和权限控制。
- Vue/Nuxt 前端与 Docker 交付。
- 可重复评测和问题诊断。

## 二、MVP 边界

### 必须完成

- 一个 MySQL 管理数据库和一个合成业务数据库。
- 经营、财务、预算、回款和 KPI 核心表。
- 可重复生成的 24 个月合成数据及预设异常。
- 指标语义模型、业务知识和标准问答。
- 自然语言到安全只读 SQL 的完整链路。
- 查询结果、图表、报告、多轮追问和执行日志。
- 至少 40 道评测问题。
- Docker 部署、README、架构图和演示材料。

### MVP 暂不完成

- 真实 ERP、CRM、BIP 或财务系统连接。
- 自动执行付款、记账、审批等写操作。
- 多 Agent、A2A 和无人值守业务操作。
- Python 沙盒深度分析，除非 SQL-only MVP 已全部通过。
- 为了视觉展示重写整个上游前端。

## 四、标准演示问题

MVP 至少支持：

1. 查询今年各部门销售额和同比变化。
2. 哪个部门本月预算执行率最高？
3. 华东部门最近三个月销售额为什么下降？
4. 查询超过 60 天仍未回款的客户和金额。
5. 哪些销售订单没有生成应收单？
6. 哪些 KPI 连续两个季度没有达标？
7. 继续查看异常部门的客户明细。
8. 将当前分析生成经营简报。

## 五、简历可写内容的判定

只有已经实现并验证的内容才能写入简历。描述格式统一为：

```text
基于 DataAgent 二次开发 + 使用合成数据 + 个人实现的具体模块 + 实际评测结果
```

不得把 DataAgent 上游现成功能写成个人从零实现，不得把目标值写成已经达成的效果。
