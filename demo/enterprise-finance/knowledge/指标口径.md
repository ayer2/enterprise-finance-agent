# 企业经营与财务指标口径

本文只描述 `enterprise_demo` 中固定种子生成的合成数据。统计日期固定为 `2025-12-31`；金额使用 `DECIMAL(18, 2)`，比率统一以小数返回，需要百分比展示时由展示层乘以 100。

## 通用口径

- 时间：销售额按 `sales_order.order_date`，回款金额按 `payment.payment_date`，预算按 `budget.period`，费用按 `expense.expense_date`，KPI 按 `kpi_target.period`/`kpi_value.period`（`YYYYQn`）。
- 组织：销售、预算、费用和 KPI 均通过 `department_id` 关联 `org_department.id`；客户维度通过订单的 `customer_id` 关联 `customer.id`。
- 边界：日期区间使用左闭右开 `[start_date, end_date)`，避免月份末日和时分秒歧义。
- 除零：所有比率使用 `NULLIF(denominator, 0)`；分母为 0 时返回 `NULL`，不解释为 0%。
- 审核：销售额只统计 `sales_order.status = 'APPROVED'`；预算执行率只统计 `expense.status = 'APPROVED'` 的费用。

## 核心指标

### 1. 销售额（sales_amount）

- 同义词：销售收入、订单销售额、成交额、营收（演示口径）。
- 公式：`SUM(sales_order.total_amount)`。
- 时间：按订单日期 `order_date`。
- 组织：按订单所属部门 `department_id`。
- 排除：排除非 `APPROVED` 订单；不使用合同金额或订单明细重复汇总。

```sql
SELECT SUM(so.total_amount) AS sales_amount
FROM sales_order so
WHERE so.status = 'APPROVED'
  AND so.order_date >= '2025-01-01'
  AND so.order_date < '2026-01-01';
```

### 2. 回款率（collection_rate）

- 同义词：收款率、应收回款率、回款完成率。
- 公式：指定应收范围内的累计回款金额 / 应收金额，即 `SUM(payment.amount) / SUM(receivable.receivable_amount)`。
- 时间：默认先按应收所对应订单的 `order_date` 选定应收范围，再累计这些应收截至查询日的回款；若问题明确说“期间收到多少钱”，则按 `payment_date` 统计回款金额，不能混用。
- 组织：应收通过 `receivable.order_id -> sales_order.department_id` 归属部门。
- 排除：缺失应收的订单不进入分母；使用预聚合回款避免一笔应收多次付款导致分母重复。

```sql
WITH payment_by_receivable AS (
    SELECT receivable_id, SUM(amount) AS paid_amount
    FROM payment
    WHERE payment_date < '2026-01-01'
    GROUP BY receivable_id
)
SELECT SUM(COALESCE(p.paid_amount, 0))
       / NULLIF(SUM(r.receivable_amount), 0) AS collection_rate
FROM receivable r
JOIN sales_order so ON so.id = r.order_id
LEFT JOIN payment_by_receivable p ON p.receivable_id = r.id
WHERE so.status = 'APPROVED'
  AND so.order_date >= '2025-01-01'
  AND so.order_date < '2026-01-01';
```

### 3. 预算执行率（budget_execution_rate）

- 同义词：预算使用率、预算消耗率、费用预算占用率。
- 公式：已审核费用 / 预算金额。
- 时间：预算 `period` 为 `YYYY-MM`；费用用 `DATE_FORMAT(expense_date, '%Y-%m')` 对齐月份。
- 组织：预算与费用必须按相同 `department_id`、月份、`category` 对齐后汇总。
- 排除：费用只统计 `APPROVED`；无预算时比率为 `NULL`，不能把预算重复乘以费用行数。

```sql
WITH expense_monthly AS (
    SELECT department_id, DATE_FORMAT(expense_date, '%Y-%m') AS period,
           category, SUM(amount) AS expense_amount
    FROM expense
    WHERE status = 'APPROVED'
    GROUP BY department_id, DATE_FORMAT(expense_date, '%Y-%m'), category
)
SELECT SUM(COALESCE(e.expense_amount, 0))
       / NULLIF(SUM(b.budget_amount), 0) AS budget_execution_rate
FROM budget b
LEFT JOIN expense_monthly e
  ON e.department_id = b.department_id
 AND e.period = b.period
 AND e.category = b.category
WHERE b.period = '2025-12';
```

### 4. 逾期应收余额（overdue_receivable_balance）

- 同义词：逾期应收、超期欠款、到期未回款、逾期欠款。
- 公式：`SUM(receivable_amount - received_amount)`。
- 时间：`due_date < as_of_date`，统计日期固定为 `2025-12-31`；逾期天数为 `DATEDIFF(as_of_date, due_date)`。
- 组织：通过订单所属部门归属；客户通过订单关联。
- 排除：余额必须大于 0；未到期和已结清应收不计入。

```sql
SELECT SUM(r.receivable_amount - r.received_amount) AS overdue_receivable_balance
FROM receivable r
WHERE r.due_date < '2025-12-31'
  AND r.receivable_amount > r.received_amount;
```

### 5. KPI 完成率（kpi_completion_rate）

- 同义词：指标达成率、KPI 达成率、目标完成率。
- 公式：`actual_value / target_value`。
- 时间：按季度字段 `YYYYQn` 精确匹配。
- 组织：实际值和目标值按相同 `kpi_id`、`department_id`、`period` 对齐。
- 排除：目标值为 0 时返回 `NULL`；不能跨 KPI 或跨季度错配。

```sql
SELECT d.name AS department_name, kd.name AS kpi_name,
       kv.actual_value / NULLIF(kt.target_value, 0) AS kpi_completion_rate
FROM kpi_value kv
JOIN kpi_target kt
  ON kt.kpi_id = kv.kpi_id
 AND kt.department_id = kv.department_id
 AND kt.period = kv.period
JOIN kpi_definition kd ON kd.id = kv.kpi_id
JOIN org_department d ON d.id = kv.department_id
WHERE kv.period = '2025Q4';
```

## 辅助指标

- 回款金额：按问题指定的 `payment_date` 区间汇总 `payment.amount`。
- 应收余额：`receivable.receivable_amount - receivable.received_amount`，余额大于 0 才是未结清。
- 逾期天数：`DATEDIFF('2025-12-31', due_date)`，仅对统计日前到期且未结清的应收有意义。
- 预算超支：`budget_execution_rate > 1`；恰好等于 1 表示用满预算，不是超支。
- KPI 未达标：`actual_value < target_value` 或完成率小于 1。
